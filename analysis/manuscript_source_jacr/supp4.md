#T Supplement 4. A minimum reporting dataset for ultrasound in suspected intestinal malrotation, and how to re-audit against it

#N Supplement to the same manuscript.

#H1 A. What the dataset is

#N The dataset lists the statements an ultrasound report would need to contain for a reader to tell whether the examination resembled those on which published performance rests. Its technique elements are those to which the literature cited in the manuscript attributes that performance (Menten 2012; Hennessey 2014; Nguyen 2021, 2022 and 2025; McCurdie 2024); the whirlpool sign is from Shimanuki 1996, and study adequacy from El-Ali 2025, in which 25.7% of examinations were non-diagnostic on the original report. Each element is stated whether the finding is normal, abnormal or not obtained, so that an omitted step can be told from a normal one.

#N The dataset is a proposal derived from this audit. It has not been validated, its effect on documentation or on detection has not been tested, and it prescribes no technique beyond what the cited literature describes. It records what was done; it does not make an examination adequate.

#TABMRD

#N The last column is the baseline from this audit: the consensus coding of the 117 ultrasound index examinations by the two readers, applying the written criteria of Supplement 1, Section K3. The baseline was measured in children with surgically confirmed malrotation, most of whom had volvulus; documentation in children investigated for suspicion may differ.

#H1 B. Re-auditing against the dataset

#N **No reference standard is needed.** Documentation is a property of the report, not of the child's diagnosis. It can therefore be audited prospectively in every examination requested for suspected malrotation, without operative follow-up, unlike sensitivity or report-level detection, which require the outcome.

#N **Population and unit.** All ultrasound examinations requested for suspected malrotation or volvulus in a defined period. Reports of one session issued on the same day are pooled into one unit, as in this audit, because some departments issue separate gastrointestinal and vessel reports for a single session.

#N **Coding.** Each element is coded documented or not documented from the findings and conclusion text, against the rule in the third column. Two independent readers with adjudication of disagreements, as here, or one reader with a double-coded sample, allow agreement to be reported. Text patterns alone are not sufficient: in this audit the pattern for the artery–vein relationship disagreed with the readers' consensus in 9 of 117 examinations (Supplement 1, Table S2).

#N **Measures.** The proportion of examinations documenting each element, with Wilson 95% confidence intervals, compared with the baseline above. Targets are for each department to set; we propose none, as no evidence-based standard exists.

#N **What a re-audit cannot show.** A rise in documentation shows that reports changed, not that examinations became more accurate. Whether documenting these elements changes detection or accuracy requires outcome data and a diagnostic accuracy design.
